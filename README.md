# PPT蒸馏器

把好看的演示蒸馏成 HTML 模板，让编码智能体挑一套，直接蒸出你的下一场演示。

用这张库的智能体先读 [`AGENTS.md`](./AGENTS.md)——那是配方手册：怎么读 `index.json`、把需求和模板匹配、克隆、再换成用户自己的内容。

## 快速开始

把下面这段话复制给你的编码智能体，它就知道怎么开蒸：

```
克隆 https://github.com/pokocat/html-template-pack，按 AGENTS.md 的说明，帮我做一份拿得出手的 HTML 幻灯片演示。
```
